# 操作手册（Ops Playbook）

## 0. 新机器校准（首次必做，5 分钟）
1. 连接模拟器，`wm size` 记下 W×H；换算不是 750×1334 时，按比例缩放坐标或直接用 `scripts/winter.sh`（自动换算）。
2. 截图，核对以下锚点（基准坐标）：
   - 底部导航 6 个图标在 y≈1268：50/190/290/435/555/690。
   - 邮件图标 (690,1240)；常规活动 (695,185)。
   - 城镇中央熔炉 (395,500)；竞技场 (430,1050)。
3. 若发现偏移：量出实际位置，重算比例，写回 `coordinates.md`（或用 config 覆盖）。
4. 校准动作建议用**返回 + 截图**验证，不要先做任何消耗资源的操作。

## 1. 助手脚本 `scripts/winter.sh`
```bash
export ADB="D:/.../adb.exe"
export SERIAL=emulator-5554
./winter.sh shot a.png          # 截图
./winter.sh tap 375 1050 2     # 连点2次
./winter.sh hold 375 1230 1500 # 长按1.5秒
./winter.sh key 4              # BACK
./winter.sh batch "input ...; sleep 1; input ..."
./winter.sh pull                # 拉取当前游戏画面为 latest.png
```
脚本会把 750×1334 坐标自动缩放到当前分辨率；也接受 `SIZE=1080x1920` 环境变量。

## 2. 常用流程

### 2.1 领邮件
底部/右侧邮件图标 → 「一键已读&领取」(555,1293) → BACK。
维护补偿邮件有时要点开单封邮件 → 「领取」(375,1050)。

### 2.2 建造/升级（含家具）
点建筑 → 「升级」→ 看“需要条件”：
- 若条件含“该建筑全部家具升到当前上限”：面板右侧家具升级大按钮(640,690) 连点，直到百分比 100%，升级键出现。
- 点「升级」→ 进入建造队列。
- 秒完成：点建筑 →「建造加速」→「一键使用」→ 确认「使用」。
- 队列留空=浪费；熔炉优先。

### 2.3 研究
科研所 →「研究」(510,920) → 选「经济/发展」页 → 点目标节点 → 「研究」(535,1065) → 回城 → 科研所 →「加速」(440,915) →「一键使用」(375,893) →「使用」(375,1005)。
研究队列保持不停；发展类优先（建造速度→研究速度→训练速度→行军队列）。

### 2.4 训练士兵
兵营 →「训练」(515,890) → 选兵种/数量（数量框 560,1015，DEL 清空 + `input text N` + 确定 692,1290）→ 训练 →「加速」(535,1145) →「一键使用」(375,925) →「使用」(375,1030)。
- 训练耗石，石不足改小批量。
- 训练加速优先 1 分钟券，溢出时间返还背包。

### 2.5 探险 + 挂机收益
底部「探险」→ 绿色「领取」(645,865) = 石+经验挂机收益（上限约 9 小时）。
推关：选关卡 → 战斗(545,1215) → 自动(685,905) + 倍速(685,1005 连点) → 胜利后「继续探险」(540,1015) / 失败「返回城镇」(235,1015)。
- 探险「探险」按钮常单击无效：在 (250/375/500)×(1130~1250) 网格连点。
- 每关奖励约 10 钻+石+碎片/技能书；失败无损失。

### 2.6 竞技场
城镇南侧圆形建筑(430,1050) → 每日 5 次免费挑战 → 选对手 → 战斗。
竞技场用**探索技能**；阵容：前排谢尔盖+杰西，后排茉莉+吉娜+巴希提。

### 2.7 联盟
- 捐献：联盟→联盟科技→节点(170,480)→长按「捐献」(535,1060) 3 秒批量；用金条 1,000/次；**左侧橙色钻石按钮绝不点**。每日 25 次，约每 8 分钟恢复 1 次。
- 互助：联盟互助(540,1045)，有请求就帮。
- 宝箱：联盟宝箱(620,667)，能领就领。
- 集结：只在有盟友在线/已有他人集结时加入；单人发起雪怪/洞狮集结必被取消（人数不足）。

### 2.8 世界地图采集
野外 → 放大镜(50,875) → 类型行横滑选资源 → **长按搜索 1500ms**(375,1230) → 结果卡片「采集」(375,652) → 出征页「出征」(545,1240，单击无效则网格连点)。
- 采集不耗体力；3 队全派出，比例肉:木:煤:铁 ≈ 20:20:4:1。
- 无石矿；石靠探险/情报/任务/资源卡。
- 空地块「迁城」绝不点。

### 2.9 英雄
- 升级：英雄→选人→「升级」连点；经验不足弹出「获取更多」→ 只点绿色「使用」（免费经验瓶），橙色「购买并使用」是钻石。
- 升星：属性页右下(645,910) → 信物满条 → 升星；拼图不够点「兑换」(120,1218)（1 拼图=1 信物）。
- 技能：技能页升级，受星级限制；优先远征技能。
- 特训营：最低教官等级决定全员上限。

### 2.10 资源卡（背包隐形金库）
背包→资源页→点资源卡→「使用」/「全部使用」。
- 带盾「1万XX（安全）」卡使用后**每种资源各给 1 万**。
- 超保护上限会弹警示→「坚持使用」(530,833)（超额部分守城失败会损耗，按需开）。
- 精确数量：数量框(520,700) → 数字键盘 → 确定(700,1290)。

### 2.11 每日任务/活动
- 每日任务入口=右上清单图标；「一键领取」经常无效，逐个「领取」(615,y) 点。
- 每日里程碑宝箱点开自动发放。
- 常规活动：只领免费；「社区关注」会跳外部 App，跳过。
- 7 日签到：每天 22:00 后领次日。
- 生存者试炼：tab 130/285/440/590/710 (y540)；积分宝箱(690,415) 5/25/50/80/120 档；奖励以资源卡进背包，记得用掉。
- 超值活动：只领免费档，别点“继续领取/选择礼包”。

## 4. 模拟器/网络恢复
### 4.1 MuMu
```bash
MuMuManager.exe info -v 0          # 看 is_process_started
MuMuManager.exe control -v 0 launch  # 未启动则启动（可能需重试一次）
adb connect 127.0.0.1:16384        # 冷启动 2~4 分钟
```
启动后截图 → 点桌面「无尽冬日」图标 → 进游戏关充值弹窗(705,45) → 领离线收益(375,1055)。

### 4.2 维护
- 滚动公告「N 分钟后将开始维护」是系统消息，不是任务。
- 维护中「无网络」= 服务器维护；等公告倒计时；维护后领补偿邮件。

### 4.3 卡死
`keyevent 4` → 左上返回 → 仍不行：
```bash
adb shell am force-stop com.gof.china
adb shell monkey -p com.gof.china 1
```
（包名以实际为准：`adb shell pm list packages | grep -i gof`）

## 5. 节奏建议
- 一个 tick 15~30 分钟：先领（邮件/挂机/签到/活动）→ 再清队列（研究/建造/训练）→ 再打（探险/竞技场/采集）→ 最后红点。
- 每 3~4 小时领一次挂机收益；训练/研究队列空了就补。
- 大活动（最强领主/建筑竞赛）前存加速和资源，活动期集中用。
- 战力不是唯一指标：兵营/使馆/科研跟得上熔炉，避免“虚胖”。
