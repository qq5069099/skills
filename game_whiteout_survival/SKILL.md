# 无尽冬日代练（Whiteout Survival Autoplay）

## 0. 一句话流程
**截图定位 → 按优先级处理 → 多点/长按 → 等结算 → 截图验证 → 记录进度**。
游戏 UI 单击经常失灵、结算慢，可靠性优先于手速；批量命令减少往返。

## 1. 安全红线（永远不碰）
- ❌ 不注入、不改客户端、不装第三方外挂——只用 adb 模拟正常点击。
- ❌ **不花钻石**：不抽卡、不买礼包、不用钻石加速、不点“立即完成”。钻石只留给第二建造队列/背包扩容/折扣体力，且需用户同意。
- ❌ 不充值：储值有礼、超值活动、特惠周卡、情报月卡一律跳过。
- ❌ 不点危险按钮：解散联盟、迁城、退出联盟、发布联盟公告、删除全部邮件、钻石捐献、天赋重置。
- ✅ 大额资源/加速使用前先截图确认；拿不准就跳过并记入待办。

## 2. 环境与连接（换机器只改这两行）
```bash
ADB="D:/Program Files/Netease/MuMu/nx_main/adb.exe"   # 改成你的 adb
SERIAL=emulator-5554                                   # adb devices 里的目标
"$ADB" -s "$SERIAL" shell wm size                      # 记录分辨率
"$ADB" -s "$SERIAL" exec-out screencap -p > shot.png
```
- MuMu：`adb connect 127.0.0.1:16384`；LDPlayer：`127.0.0.1:5555`；BlueStacks：`5555/5556`；真机直接插 USB。
- **多设备/多别名时必须 `-s` 指定 serial**（MuMu 常同时出现 `emulator-5554` 与 `127.0.0.1:16384`，不加会报 “more than one device”）。
- 本技能坐标以 **750x1334 竖屏**为基准。其他分辨率按比例换算：
  `x' = round(x * W / 750)`，`y' = round(y * H / 1334)`。
- 首次在新机器使用先做**校准**（见 `references/ops-playbook.md` §0）：截图确认底部导航、邮件、右侧活动入口位置。

## 3. 操作基本功（可靠性 > 速度）
- 点击：`input touchscreen swipe X Y X Y 80`（比 `input tap` 稳）。
- **单击经常无效**：关键按钮连点 2~3 次；世界地图「搜索」长按 1500ms；商品价格条长按 900~1000ms；联盟捐献长按 3000ms 批量。
- 结算慢：点完等 2~30 秒再截图；跨页面连招之间至少 3~5 秒，否则只生效第一个。
- 同屏已知坐标合并成一条 `adb shell` 执行：`input ... 80; sleep 1; input ... 80`。
- 只在跨页面/关键节点截图验证；同页连续操作可 3~5 步一验。
- 误入未知页面：先 `keyevent 4`，再用左上返回箭头 (45,40)，不要乱点。

## 4. 每轮优先级（Tick 流程，从上到下）
1. **截图定位**：城镇 / 世界地图 / 面板 / 弹窗。
2. **邮件**：一键已读&领取（(555,1293)），维护补偿必领。
3. **每日任务 + 签到 + 常规活动**免费奖励；超值活动只领免费档，别点“继续领取/选择礼包”。
4. **探险**：领取挂机收益（石+经验，上限约 9h）；打免费关卡。
5. **联盟**：捐献（长按批量，金条 1,000/次，钻石捐献不点）、互助、宝箱、科技、有盟友才发起集结。
6. **训练**：兵营训练 + 训练加速，训练队列尽量不停。
7. **研究**：研究队列不停（优先发展类，见 §6）。
8. **建筑**：建造队列不停，熔炉优先（见 §5）。
9. **英雄**：免费经验升级、可升星就升星、技能书升级；红点必清。
10. **采集**：行军队列全部派出，肉:木:煤:铁 ≈ 20:20:4:1。
11. **红点清零**：英雄/背包/野外/活动/邮件/左侧队列箭头。
12. **背包资源卡**按需开启（升级前开，避免暴露被掠夺；带盾卡=全资源各 1 万）。

## 5. 熔炉与建筑（核心）
- 优先级：**大熔炉 > 大使馆 > 三兵营 > 科研所 > 指挥部**；军医所 > 仓库 > 城墙；资源建筑（伐木/煤矿/铁矿/厨房等）最后。
- 熔炉等级 = 全局限速；其他建筑不能超过熔炉。**只升当前熔炉条件需要的建筑**，不分散资源。
- 建筑升级通常要求“该建筑全部家具升到当前上限”：面板右上百分比到 100% 才出现升级键；家具升级按钮(640,690)可连点，满了自动切下一个。
- 关键节点：熔炉 7=联盟/世界地图；9=英雄装备；10=T3 兵/联盟锦标赛；22=领主装备；25=领主宝石；30=火晶时代。
- 建造队列不留空；加速券优先给熔炉/长计时，**平时囤，活动（最强领主/建筑竞赛）再用**。
- 建造加速流程：点建筑 →「建造加速」→「一键使用」→ 确认「使用」。
- 实例：熔炉 14→15 需 使馆14 + 矛兵营14 + 肉460万 + 木460万 + 煤93万 + 石。

## 6. 科技研究
- 顺序：**发展类先满**——建造速度 → 研究速度 → 训练速度 → 行军队列+1；再战斗类（盾兵生命/防御优先，再矛/弓攻击）；经济类最后。
- 研究流程：科研所 → 研究(510,920) → 点节点 → 研究(535,1065) → 回城 → 科研所 → 加速(440,915) → 一键使用(375,893) → 使用(375,1005)。
- 研究加速平时适量用 1~5 分钟券，大券留给活动。

## 7. 英雄
- 零氪核心：**茉莉**（主C，签到送，低血爆发）/ **谢尔盖**（唯一盾）/ **杰西**（集结打熊 +25% 全队伤害）/ **巴希提**（竞技场）/ **吉娜**（省体力）。
- 竞技场阵容：前排 谢尔盖+杰西，后排 茉莉+吉娜+巴希提。竞技场用**探索技能**，兵种克制：盾 > 矛 > 弓 > 盾。
- 等级上限 = **熔炉等级 + 20**；升级用免费经验瓶，经验不足时点按钮会弹“获取更多”，只点绿色「使用」，橙色「购买并使用」=钻石，绝不点。
- 升星只给主力；**金色通用碎片留给二代以后英雄**，别给一代。
- 特训营：最低教官等级决定各席位上限，先拉最低的。
- 技能书优先远征技能（集结全队生效）；技能升级受星级限制（2→3 需 2 星、3→4 需 3 星）。

## 8. 资源与钻石
- 采集比例 肉:木:煤:铁 ≈ **20:20:4:1**；0~22 级最缺资源，22 级后最缺加速。
- 石料来源：探险、情报猎兽、每日任务、背包资源卡；**世界地图没有石矿点**。
- 背包「资源」页 = 隐形金库：带盾的「1万XX（安全）」卡使用后**每种资源各给 1 万**；开卡会弹警示（超保护上限），点「坚持使用」；按需开。
- 商人：免费刷新，资源换资源（长按价格条购买），只换缺的资源。
- 钻石绝不抽卡；招募只点免费次数。

## 9. UI 地图与危险区（750x1334）
- 底部导航 y≈1268：探险(50) / 英雄(190) / 背包(290) / 商店(435) / 联盟(555) / 野外·城镇(690)。
- 右上/右侧：常规活动(695,185)、超值活动(695,295)、7日签到(690,420)、生存者试炼(690,540)、邮件(690,1240)。
- 左侧面板箭头(35,610)：建造/训练/研究队列定位。
- 返回：`keyevent 4`（BACK）；城镇里按 BACK 会弹“确认退出游戏”→ 点取消(220,818)。
- ⚠️ 联盟「管理」页有橙色**解散联盟**：误入立刻点左上返回(45,40)。
- ⚠️ 空地块卡片有「迁城」，绝不点。
- ⚠️ 联盟公告编辑页：X(695,165) 关闭，别点“确认”发布。
- 完整坐标表：`references/coordinates.md`。

## 10. 故障恢复
- 模拟器未启动/离线：`MuMuManager.exe info -v 0` → `control -v 0 launch`（可能要点两次）；冷启动 2~4 分钟。
- 维护中：「无网络」= 服务器维护，不是本地问题；等公告倒计时，维护后领补偿。
- 卡死：BACK → 不行就 `am force-stop com.gof.china` 重开；进游戏关充值弹窗(705,45)、领离线收益(375,1055)。
- **「账号已在其他设备登录，被强制下线」= 用户本人正在手机/另一台机器上玩**：立即停止自动操作并询问用户，**不要反复点「重新连接」**（会互相顶号）。多机部署时先约定同一时间只由一台机器托管。
- 详细恢复步骤见 `references/ops-playbook.md`。
